## Start here

1. [Install with npm, a candidate archive or Docker](/installation), then run the terminal setup wizard.
2. [Configure a music provider](/providers/) and [authorize the connection](/provider-connections). Provider accounts are optional during installation.
3. Connect [ChatGPT](/clients/chatgpt), [Claude](/clients/claude) or [another MCP client](/clients/) using the endpoint printed by setup, then complete owner OAuth consent.
4. Explore [playlist workflows](/playlist-automation) or the [generated MCP tool reference](/tools-reference).

For local administration, see [operations and backups](/operations) and
[CLI information, updates and notices](/cli-information). Remote access requires
reachable HTTPS; there is no web administration dashboard.

English is canonical. Start in [Polski](/pl/), [Deutsch](/de/),
[Français](/fr/) or [Español](/es/) for localized guidance and English references.
