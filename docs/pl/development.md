# Development

Uruchom `npm ci`, a następnie `npm run format`, `npm run lint`, `npm run typecheck`, `npm test`, `npm run build` i `npm run docs:build`. Przy dodawaniu narzędzia zaktualizuj rejestrację, testy i `tools-reference.md`. Zachowaj istniejące nazwy publiczne, używaj mocków Spotify i nie commituj credentiali.
