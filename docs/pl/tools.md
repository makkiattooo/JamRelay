# Narzędzia MCP

Implementacja rejestruje dokładnie 39 narzędzi do wyszukiwania, odczytu i zapisu playlist, biblioteki, danych osobistych oraz odtwarzania. Pełna referencja, wraz z nazwami i ograniczeniami, znajduje się na stronie [MCP tools](/tools), która jest źródłem kanonicznym dla nazw technicznych.
