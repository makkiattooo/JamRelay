# Entwicklung

Führe `npm ci`, `npm run format`, `npm run lint`, `npm run typecheck`, `npm test`, `npm run build` und `npm run docs:build` aus. Bei neuen Tools Registrierung, Tests und Tool-Referenz aktualisieren. Öffentliche Namen und Verhalten unverändert lassen; keine Secrets oder Live-Spotify-Daten committen.
