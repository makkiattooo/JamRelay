# MCP-Tools

TuneLink stellt 39 Tools für Katalogsuche, Playlist- und Bibliotheksverwaltung, persönliche Empfehlungen sowie Playback bereit. Lese-Tools ändern Spotify nicht; Schreib-Tools sollten vom Client bestätigt werden.

`get_artist_top_tracks` bleibt aus Kompatibilitätsgründen registriert, liefert aber `spotify_feature_removed`, weil Spotify den Endpunkt entfernt hat. Für Argumente, Ergebnisse, Spotify-Scopes, Chunking und Rollback siehe [Tool-Verträge](/de/tools-reference).
