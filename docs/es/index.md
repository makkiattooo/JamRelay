# JamRelay

Un servidor MCP autoalojado para conectar asistentes de IA con tu propia cuenta de Spotify.

[English documentation](/) · [Polski](/pl/) · [Deutsch](/de/) · [Français](/fr/) · [Español](/es/)

> **Proyecto no oficial.** JamRelay no está afiliado, respaldado ni patrocinado por Spotify, OpenAI, Anthropic, Google ni otros proveedores de plataformas de IA.

La documentación inglesa es la fuente canónica para los detalles técnicos, variables, rutas API y nombres de herramientas MCP. Incluye instalación, OAuth, clientes, seguridad y despliegue.
