# Outils MCP

TuneLink expose 39 outils pour le catalogue, les playlists, la bibliothèque, la découverte personnelle et la lecture. Les outils d’écriture doivent être confirmés par le client.

`get_artist_top_tracks` reste enregistré pour compatibilité mais renvoie `spotify_feature_removed`, car Spotify a supprimé l’endpoint. Les arguments, scopes, résultats, chunks et rollbacks sont détaillés dans [les contrats d’outils](/fr/tools-reference).
