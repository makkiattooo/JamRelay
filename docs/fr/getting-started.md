# Démarrage rapide

Il faut Node.js 22+ ou Docker et une application Spotify Developer. Copiez `.env.example` vers `.env`, renseignez vos valeurs puis lancez `npm ci` et `npm run dev`. Ouvrez `/auth/spotify/login`, autorisez Spotify et connectez le client MCP à `/mcp`. Consultez les pages [installation](/fr/installation), [OAuth](/fr/oauth) et [sécurité](/fr/security) avant une exposition publique.
